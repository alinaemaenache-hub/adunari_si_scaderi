# Lumea Sofiei

Joc zilnic de antrenament la matematică (adunare și scădere, probleme de clasa a III-a), cu medalii, niveluri, insigne și avatar personalizabil.

## Cum pornești

Deschide `index.html` într-un browser. Nu are nevoie de server sau de instalare.

## Publicare pe GitHub Pages

1. Pune `index.html` în rădăcina repository-ului.
2. Settings → Pages → Source: „Deploy from a branch”, branch `main`, folder `/ (root)`.
3. După un minut aplicația e disponibilă la `https://<utilizator>.github.io/<repository>/`.

## Unde se salvează progresul

Progresul (nivel, XP, insigne, serie, istoric, setări) se salvează în browserul dispozitivului (localStorage). Folosește același dispozitiv și același browser, și nu șterge datele site-ului, ca să nu se piardă seria.

Colțul părinților: răspunsul la întrebarea de acces este 84.
